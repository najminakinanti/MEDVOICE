Perekaman

Siap.

Dua mikrofon: label pembicara pasti. Satu mikrofon: pembicara tidak diketahui, sehingga diagnosis ditandai untuk konfirmasi dokter.

Dua file (dokter + pasien) = label pembicara pasti. Satu file campuran = pembicara tidak diketahui. Format: wav, mp3, m4a, ogg, webm, flac.
